# 003 — REFRACTION

**COMPLETE / LOCKED.** Perception changes the thing perceived. Further changes are limited to functional bug fixes unless explicitly reopened.

One asymmetric optical body samples a shared type, grid and geometric-resolution field. Its fragment shader separates clear core magnification, nonlinear middle displacement and steep peripheral distortion. Speed adds bounded stretch and dispersion; pressure increases optical power. The body retains its placement and settles through a damped spring.

Run `npm start` from this folder (Python 3 required), then open http://127.0.0.1:8768. No dependencies or build step. `npm test` uses Node.js 22+.

Drag the body to inspect; hold it to intensify. Touch uses the same controls. With the canvas focused, arrow keys move it and Space applies pressure. Reduced motion suppresses momentum and velocity effects. Background tabs pause work. The calibration field is drawn once per resize; only the optical shader runs per frame, with capped pixel ratio.

Plain JavaScript, Canvas 2D source texture, and WebGL. No imported assets, decorative imagery, framework, or external service.
